## WATER THERMODYNAMIC PROPERTIES
This is a educational project written on my time off, to calculate water thermodynamics properties guide on concepts of Object Oriented Programming.
To visualize water charts properties I forked from [MPAndroidChart](https://github.com/PhilJay/MPAndroidChart); you may need update or add depencencies from [MPAndroidChart](https://github.com/PhilJay/MPAndroidChart).

Currently I am rewriting on [Rust Language](https://rust-lang.org/) to compare the performance, foot print and energy consumption.
